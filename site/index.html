Why CPAMP

CPA routes the traffic. CPAMP makes it visible and manageable.

Day-to-day gateway configuration and long-term observability in one local panel, answering the three questions operators ask most.

01Request monitoring & failure diagnosis

Why are requests failing?

Every request from the CPA usage queue is persisted to local SQLite. Browse live requests by account or caller API key and pinpoint problems in seconds.

  • Status, latency, tokens, cache and trace at a glance
  • Redacted failure evidence, never the raw failure body
  • Import and export request history as JSONL
Try the monitoring demo
02Cost & usage analytics

Where is the money going?

Break down requests, tokens, cost, latency and failures by model, provider, account, auth file, API key, project, channel and time range.

  • Separate input, output, reasoning and cache tokens
  • Service tier and long-context pricing semantics
  • Model prices synced from LiteLLM and OpenRouter, with local overrides
Try the usage analytics demo
03Account health, quotas & automation

Are accounts and quotas healthy?

Inspect Codex and xAI accounts on a schedule, in the browser or on Manager Server, and catch broken credentials and draining quotas early.

  • Quota windows, reset evidence, credential and workspace status
  • Controlled cooldown when a quota is clearly exhausted
  • Auth failures collected in a review queue you can recover from

FAQ

Frequently asked questions

What is CPA Manager Plus?

CPA Manager Plus (CPAMP) is a self-hosted management panel and observability dashboard for CPA / CLIProxyAPI. It manages providers, credentials, OAuth, plugins and configuration, and keeps request history, cost analytics, quota windows and account automation state.

Does CPAMP proxy model requests?

No. CPAMP manages and observes traffic that flows through CPA / CLIProxyAPI. It is not a model proxy and does not forward model requests on its own.

What is the difference between the Lightweight Panel and Full Mode?

The Lightweight Panel replaces the management UI that CPA serves at :8317/management.html and adds no services or databases. Full Mode runs Manager Server at :18317/management.html for persistent request history, cost analytics, server-side inspection and automation.

Where is my data stored?

In local files on your own machine. Request history lives in SQLite, and the CPA Management Key is encrypted with a local data.key; back up both together. There is no sign-up and no telemetry SDK.

Which providers are supported?

Everything CPA supports, including Codex, Claude, Gemini, Vertex, xAI, Devin, Muse / Meta and OpenAI-compatible providers. Account inspection and quota automation currently cover Codex and xAI.

Is CPA Manager Plus free?

Yes. It is open source under the MIT license, with Docker images and native packages for Linux, macOS and Windows on amd64 and arm64.
