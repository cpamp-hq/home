自托管 · 本地 SQLite 持久化 · 零遥测 SDK

面向 CPA / CLIProxyAPI 的自托管管理面板与可观测性仪表盘

在一个本地面板中管理 Provider、认证文件、OAuth、插件和配置，并持久化请求历史、用量成本分析、配额窗口、失败诊断与账号自动化状态。

CPAMP 管理和观测经过 CPA / CLIProxyAPI 的流量，本身不是模型代理，也不会独立转发模型请求。无需注册账号，所有数据保存在你自己的本地文件中。

CPAMP 可以帮你回答什么问题？

把网关日常配置与长期可观测性收敛进同一个自托管界面。

请求为什么失败？

在本地 SQLite 持久化请求历史中查看失败率、状态码、延迟、Trace、受影响的模型与账号，以及脱敏失败摘要，不暴露原始失败体。

查看请求监控演示 (1.x)

成本花在哪里？

按模型、Provider、账号、认证文件、API Key、项目、渠道和时间范围拆解请求、Token（含 reasoning / cache）与预估成本，支持模型价格同步与本地覆盖。

查看用量分析演示 (1.x)

账号和配额是否健康？

统一管理 Provider 凭证与 OAuth，定时巡检 Codex 与 xAI 账号，读取配额窗口与重置证据，并对额度耗尽或异常凭证执行受控冷却与处理队列汇总。

两种部署方式，按需演进

CPAMP 轻量面板
